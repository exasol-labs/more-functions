.. _connection_id:

CONNECTION_ID
-------------

``CONNECTION_ID()`` returns the current Exasol session identifier.

Syntax
------

.. code-block:: sql

   CONNECTION_ID()

DESCRIPTION
-----------

================== ================= ===============
Parameter / Return Type              Range
================== ================= ===============
Return             ``DECIMAL(20,0)``
================== ================= ===============

Returns the session ID.
